# skillkit — Implementation Plan

> **For Claude:** Executed via subagent-driven development. Each Task A–F
> dispatched to a fresh implementer subagent, then two-stage reviewed
> (spec compliance → code quality). Tasks A–E share the package
> directory but touch disjoint files. Task F is docs.

## Goal

First reference Go implementation of the [agentskills.io open
standard](https://agentskills.io) — adopted by 40+ AI tools (Claude
Code, Cursor, GitHub Copilot, VS Code, Junie, Gemini CLI, OpenAI Codex,
Goose, OpenHands, Snowflake Cortex, Spring AI, ByteDance Trae, Roo Code,
Letta, etc.).

Replaces hand-rolled markdown loaders in 7 internal Go services
(MemDB ×2, dozor, vaelor, go-hully, go-wp) plus 36+ hardcoded prompt
constants in go-job, go-code, go-search, go-pentest. Net delta after
all migrations: **~−1000 LoC** of duplicated loader/prompt code,
+400 LoC of shared standalone library with full test coverage.

## Strategic positioning

This is a public, MIT-licensed standalone module — not an internal
go-kit subpackage:

1. No conformant Go-loader exists for the agentskills.io standard; we
   are first.
2. Public surface lets the package land on agentskills.io's "Clients"
   carousel as the Go SDK reference.
3. External contributors submit PRs without navigating an internal
   monorepo.
4. Independent semver lifecycle (skill API stability ≠ go-kit cadence).
5. Strict stdlib-only discipline avoids dependency on go-kit, so go-kit
   can later wrapper-import this package without a cycle.

## Architecture

Two independent APIs in one package, sharing frontmatter primitives:

- **`Embedded`** — single skill baked into a binary via `//go:embed`,
  optional env-path override for hot-reload, mtime-cached. Pattern A.

- **`Catalog`** + **`Resolver`** — multi-skill discovery across tiered
  sources. Built-in resolvers: `DirTier` (filesystem), `EmbedFSTier`
  (`embed.FS`), `PluginTier` (pre-resolved entries with namespacing).
  `ContextResolver` extension interface for future MCP/Langfuse
  integrations without breaking change. Pattern B.

Resolver is the extension point: tiers are `(name, Resolver)` tuples.
New sources (S3, HTTP, MCP `prompts/list`) plug in without touching
Catalog.

## Task A — Frontmatter + Metadata Primitives

**Files:** `frontmatter.go`, `frontmatter_test.go`, `metadata.go`,
`metadata_test.go`.

### Public API

```go
package skillkit

// StripFrontmatter removes a leading YAML or JSON frontmatter block
// and returns the body trimmed of leading whitespace. Input without
// a recognized fence is returned unchanged. Supports YAML ("---" fences)
// and JSON (top-level object on first line, blank line, body).
//
// CRLF input is normalized to LF before parsing. NUL bytes inside the
// body are silently stripped (bufio.Scanner stops at NUL otherwise).
func StripFrontmatter(content string) string

// ParseFrontmatter splits content into (frontmatter, body). Returns
// ("", content) when no fence is found.
func ParseFrontmatter(content string) (frontmatter, body string)

// Metadata holds parsed frontmatter fields covering the agentskills.io
// standard plus Claude Code extensions.
type Metadata struct {
    // Required by spec
    Name        string
    Description string

    // agentskills.io optional standard fields
    License       string
    Compatibility string

    // Claude Code extensions (load-bearing for Skill auto-trigger)
    WhenToUse              string  // appended to Description for discovery
    AllowedTools           []string
    DisableModelInvocation bool
    UserInvocable          *bool   // nil = default (true)

    // skillkit custom (widely useful, not in spec)
    Version string
    Locale  string
    Tags    []string

    // Top-level non-standard YAML keys + agentskills.io `metadata:` map
    Extra map[string]string
}

// ParseMetadata parses YAML or JSON frontmatter into Metadata. JSON
// when frontmatter starts with "{". The YAML parser is intentionally
// minimal: top-level scalars, quoted strings, flow lists for tags
// and allowed-tools, comments and blanks ignored. Nested maps NOT
// supported except `metadata:` whose top-level keys are flattened
// into Extra. allowed-tools also accepts space-separated string per
// spec. Unknown formats yield an empty Metadata (no error).
func ParseMetadata(content string) Metadata

// ValidateName enforces agentskills.io spec rules:
//   - 1–64 characters
//   - lowercase ASCII alphanumeric and hyphens only
//   - no leading or trailing hyphen
//   - no consecutive hyphens
//
// `dirName` is the on-disk directory name; spec mandates it matches
// `name`. Pass "" to skip the directory-name check (used by Embedded).
func ValidateName(name, dirName string) error
```

### Implementation notes

- `bufio.Scanner` buffer **must** be sized ≥1 MiB:
  `scanner.Buffer(make([]byte, 1<<20), 1<<20)`. Default 64 KiB silently
  truncates skills (typical <50 KB but no guarantee).
- No allocations on no-fence path: detect fence on first byte; return
  input unchanged. Verified via benchmark.
- CRLF normalization happens once at top of `ParseFrontmatter`
  (`strings.ReplaceAll(content, "\r\n", "\n")`).
- Description >1024 chars: slog Debug warning, no truncation.

### Tests

`frontmatter_test.go`: YAML strip happy path, no-fence unchanged, only
opening fence unchanged, empty body after frontmatter, CRLF→LF, JSON
strip, malformed JSON unchanged, NUL bytes removed, ParseFrontmatter
YAML/JSON/no-fence cases.

`metadata_test.go`: YAML scalars (every typed slot), quoted strings,
tags as flow list AND comma-separated, allowed-tools as flow list AND
space-separated, disable-model-invocation true/false/absent,
user-invocable true/false/absent, `metadata:` block keys flattened into
Extra, unknown keys land in Extra, JSON full roundtrip, JSON missing
optionals → zero values, comments + blanks ignored, ValidateName cases
(1-char, 64-char, 65-char, uppercase, underscore, leading/trailing/
consecutive hyphens, dir-mismatch, empty dir-skip).

## Task B — Embedded Skill (Pattern A)

**Files:** `embedded.go`, `embedded_test.go`, `embedded_testdata/sample.md`.

### Public API

```go
// Embedded resolves a single skill body. Use when a binary ships with
// exactly one named skill and operators may want to override it at
// runtime via an env path.
//
// Resolution per Body() call:
//   1. If EnvVar is set + path readable + file ≤1 MiB + body non-empty
//      → mtime-cached body.
//   2. Embedded default (parsed once at construction).
//
// Body() always returns non-empty. NewEmbedded panics if the embedded
// raw has empty body after frontmatter strip — build-time invariant.
//
// Embedded is safe for concurrent use.
type Embedded struct { /* unexported */ }

func NewEmbedded(name, envVar, embeddedRaw string) *Embedded
func (e *Embedded) Body() string
func (e *Embedded) Metadata() Metadata
func (e *Embedded) Diagnostic() string  // for startup logs
func (e *Embedded) ResetCache()         // test-only

// Diagnostic strings:
//   "embedded default"
//   "env override <path>"
//   "env override <path> UNREADABLE → embedded default"
//   "env override <path> TOO_LARGE → embedded default"
```

### Implementation notes

- mtime cache per-Embedded instance (isolation between unrelated skills)
- Env-override file size cap **1 MiB** — rejected at stat time (DoS)
- I/O errors logged via slog Debug, never returned
- Stat→Read race: lock per-path mutex around stat+read pair so
  concurrent callers see consistent body during file rewrite
- Symlinks via env override: not validated (operator-set value, operator
  trust)
- ValidateName(name, "") at construction; panic on invalid

### Tests

env unset, env missing path, env valid path, env mtime-change → reload,
env same mtime → cache hit, env >1 MiB → fall through, env empty body
→ fall through, file deleted between Stat/ReadFile → no panic, empty
embedded raw → panic, frontmatter-only embedded → panic, invalid name
→ panic, ResetCache invalidates, concurrent Body() (`-race`),
Metadata returns embedded (not env-override), Diagnostic format
matches all four strings.

## Task C — Resolver + Tier Implementations

**Files:** `tier.go`, `tier_test.go`, `tier_testdata/...`.

### Public API

```go
type SkillInfo struct {
    Name     string
    Path     string   // resolver-defined; "" for plugin sources
    Dir      string   // skill directory (SKILL.md's parent); populated
                      // by all tiers for resolving sibling files
                      // (references/, scripts/, assets/)
    Source   string   // tier name; "<tier>:<plugin>" for plugin tier
    Metadata Metadata
}

type Resolver interface {
    Find(name string) (info SkillInfo, body string, ok bool)
    Walk(yield func(SkillInfo))
}

type ContextResolver interface {
    Resolver
    FindCtx(ctx context.Context, name string) (SkillInfo, string, bool, error)
}

type Tier struct {
    Name     string
    Resolver Resolver
}

// DirTier: filesystem tier. Scans <dir>/<skill-name>/SKILL.md.
// Symlink entries skipped (path-traversal guard). Symlink targets
// resolved and rejected if outside dir. Empty body after strip → ok=false.
func NewDirTier(name, dir string, opts ...DirTierOption) Tier
type DirTierOption func(*dirTier)
func WithSkillFilename(filename string) DirTierOption  // default "SKILL.md"
func WithMtimeCache() DirTierOption                    // off by default

// EmbedFSTier: embed.FS tier. <root>/<skill-name>/SKILL.md.
// Walked once at construction; serves from in-memory map.
func NewEmbedFSTier(name string, fs embed.FS, root string, opts ...EmbedFSOption) Tier
type EmbedFSOption func(*embedFSTier)
func WithEmbedSkillFilename(filename string) EmbedFSOption

// PluginTier: pre-resolved entries with bare/namespaced lookup.
type PluginEntry struct {
    PluginName string
    SkillName  string
    Path       string  // optional
    Body       string  // optional pre-loaded
}
func NewPluginTier(name string, entries []PluginEntry) Tier
```

### Implementation notes

- DirTier symlink guard: `os.Lstat` entry; skip if symlink. After
  `filepath.EvalSymlinks(skillFile)`, verify
  `filepath.Rel(dir, resolved)` doesn't start with `..`.
- DirTier scans only one level deep — the spec layout is
  `<dir>/<skill-name>/SKILL.md`, no nesting. Documented as deliberate.
- DirTier empty-body guard: `StripFrontmatter` returns "" → `ok=false`
  + slog Warn with file path.
- EmbedFSTier walks fs at construction; map[string]SkillInfo by name.
- PluginTier duplicate (PluginName, SkillName) → slog Warn at construct.
- All resolvers populate `SkillInfo.Dir`.

### Tests

DirTier: Find/Walk happy path, missing dir, missing SKILL.md, custom
filename, WithMtimeCache reload, symlink entry skipped, symlink-outside
rejected, empty body → ok=false, multi-file skill → Dir resolves
sibling.

EmbedFSTier: Find from embed.FS, Walk yields all, nested layout, Dir set.

PluginTier: bare name, namespaced name, Body field used directly, Path
triggers fs read, duplicate logs Warn.

ContextResolver: Catalog detects via type assertion (stub test).

## Task D — Catalog + Summary

**Files:** `catalog.go`, `catalog_test.go`, `summary.go`, `summary_test.go`.

### Public API

```go
type Catalog struct { /* unexported */ }
func NewCatalog(tiers ...Tier) *Catalog

func (c *Catalog) List() []SkillInfo
func (c *Catalog) Load(name string) (body string, info SkillInfo, ok bool)
func (c *Catalog) LoadCtx(ctx context.Context, name string) (body string, info SkillInfo, ok bool, err error)
func (c *Catalog) LoadMany(names []string) string
func (c *Catalog) LoadManyCtx(ctx context.Context, names []string) string

type SummaryFormat int
const (
    SummaryXML      SummaryFormat = iota // <skills><skill>...
    SummaryMarkdown                       // ### name\n<description>\n
    SummaryJSON                           // [{"name":...}]
)
func (c *Catalog) BuildSummary(format SummaryFormat) string
```

### Implementation notes

- List dedup: walk in tier order, `seen[name]` filter, sort by Name.
- Load fallthrough: walk in tier order, return first ok=true.
- Type-assert each tier's Resolver in LoadCtx for ContextResolver;
  fall back to Find for non-context-aware.
- LoadMany format: `### Skill: <name>\n\n<body>\n\n---\n\n`. Trailing
  separator stripped.
- BuildSummary XML: escape `<`, `>`, `&`. Plugin grouping under
  `<skill-group plugin="...">` when Source contains ":".
- Description truncation: 180 chars in XML/Markdown, full in JSON.

### Tests

2-tier dedup first wins, Load tier-1/tier-2/all-miss, LoadMany all/
partial/empty, LoadCtx with ContextResolver stub returning error,
LoadCtx fallback to Find, zero tiers, XML happy path, XML plugin
grouping, XML escapes, Markdown 180-char truncation, JSON valid
roundtrip.
